## 2. 轴压承载力

```
N0  = Asc · fsc                                              (5.1.2-1)
fsc = (1.212 + B·θ + C·θ²) · fc                              (5.1.2-2)
θ   = αsc · fy / fc                                          (5.1.2-3)
αsc = As / Asc                                               (5.1.2-4)
Nu  = φ · N0                                                 (5.1.10-1)
φ   = 1/(2λ̄sc²) · [(λ̄sc²+1+0.25λ̄sc) − √((λ̄sc²+1+0.25λ̄sc)² − 4λ̄sc²)]   (5.1.10-2)
λ̄sc = 0.01 · λsc · (0.001·fy + 0.781)                        (5.1.10-3)
λsc = l0 / i
```
- `Asc = As + Ac`（钢管面积 + 管内混凝土面积）
- **式 (5.1.10-3) 已用表 5.1.10 逐点复核**：误差 ≤ ±0.003。

## 3. 受弯承载力

```
Mu  = γm · Wsc · fsc                                         (5.1.6-1)
Wsc = π·r0³/4 ,  r0 = √(Asc/π)                               (5.1.6-2)
γm  = 1.2                        （实心圆形截面）             (5.1.6-3)
γm  = −0.483·θ + 1.926·√θ        （其他截面，见符号说明）
```
> `Wsc` 是**实心**截面的塑性抵抗矩近似式，与截面实际几何无关（只与 Asc 有关）；
> 该写法与规范正文及两篇独立复核资料一致。

## 4. 压弯共同作用（`check()` 的核心）

```
U = N/Nu
U ≥ 0.255 :  N/Nu + βm·M / [1.5·Mu·(1 − 0.4·N/N'E)] ≤ 1     (5.3.1-4)
U < 0.255 : −N/(2.17Nu) + βm·M / [Mu·(1 − 0.4·N/N'E)] ≤ 1   (5.3.1-5)
N'E = 11.6 · kE · fsc · Asc / λsc²                          (5.3.1-3)
Esc = 1.3 · kE · fsc                                        (5.1.7-2)
```
- **`βm` 默认取 1.0**（等效弯矩系数；对无横向荷载的框架柱按规范取 1.0 偏安全）。
- **`N'E` 用 11.6 系数**，不是 π²EscAsc/λ² —— 这点很容易写错。
- 分母加了下限保护（`max(..., 0.05)`）避免 N→N'E 时除零。

## 7. 第 6 章——实心圆形简化方法（`ch6_circle()`，参考校核，非控制）

```
Nu = φe · φl · N0 ,  N0 = 0.9·Ac·fc·(1+θ)   （θ ≤ 1/(α−1)² 时）
                      N0 = 0.9·Ac·fc·(1+√θ+θ)（θ > 1/(α−1)² 时）
α  = 2.00（C30~C50）/ 1.80（C55~C80）
φl = 1 − 0.0226·(Le/D − 4)     （Le/D > 4 时）
k  = 1 − 0.625·eo/rc           （有侧移框架柱）
```
本技能把它作为**独立校核**输出，验证第 5 章结果量级，**不作为选型控制条件**
（第 5 章更通用、覆盖矩形与圆形）。

## 常见坑清单

1. **`i` 用错**：圆管 `i = D/4`；矩形 `i = √(I/Asc)` 且**两方向分别算**再取 λ 大者。
2. **λ̄sc 忘了归一化**：是 `0.01·λsc·(0.001fy+0.781)`，不是 λsc 本身。
3. **N'E 用了 π²Esc**：应乘 11.6·kE/sf，不是 π²。
4. **只控 N/Nu**：会出现压弯利用率 ≈0.99 的隐性超限，必须同时控 U_NM。
5. **矩形直接用 b×h 代 fsc 公式**：必须先换算等效正方形 √(b·h)。
6. **γm 用 1.2**：那只对**实心圆形**成立，矩形要用 `−0.483θ+1.926√θ`。
7. **θ 的范围**：太小（<0.5）不满足规范推荐、太大（>2）不经济，都要卡。
8. **壁厚按 t 选 fy**：t≤16 用 FY16，t>16 用 FY40 —— 厚板强度更低，别漏。
