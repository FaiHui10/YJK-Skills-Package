# 规范限值与公式

## 单位约定

全库统一：长度 **mm**、面积 **mm²**、力 **N**、轴力输入 **kN**、承载力 **kN**、应力 **N/mm²**。
内部换算：`N = A[mm²] × f[N/mm²]`，除以 1000 得 kN。

## 材料强度

**取值来源**：优先从种子模型的 `设计结果\wmass.out` 读（见 yjk-colmodel 技能的 `wmass`
子命令）。各结构层可能不同（例如结构层 3~10 是 C60、11~14 是 C55），程序按标准层取
**最底层有记录的自然层**的柱等级作为该标准层的设计取值。

> **叠合柱的管内（核心）混凝土等级读不到**：wmass.out 对叠合柱只报一个等级（管外那一档），
> 管内等级在模型 `.yjk` 二进制里。必须由人在 YJK 中确认，或用 `config.diehe.fc_in` 显式指定。
> 程序一律打印提醒，并在导出设计表的「设计参数」表里留出可编辑列。

混凝土轴心抗压设计值 `fc`（GB50010 表 4.1.4-1）：
C30 14.3 / C40 19.1 / C50 23.1 / **C55 25.3 / C60 27.5** / C70 31.8 / C80 35.9

钢材抗压设计值 `fa`（GB50017 表 4.4.1，按板厚）：
Q235 → 215（t≤16）/ 205（t>16）；**Q355 → 305（t≤16）/ 295（t>16）**；Q390 → 345 / 330

## 轴压比统一口径

    Uc = Nu / (fc·Ac + fa·Aa)

其中 `Ac` 混凝土面积、`Aa` 型钢/钢管面积（普通混凝土柱 `Aa = 0`）。
计算轴压比时计入型钢，是 JGJ3-2010 11.4.4 明确允许的。

## 1/2 普通混凝土柱、加芯柱

**JGJ3-2010 表 6.4.2 柱轴压比限值**

| 结构类型 | 一级 | 二级 | 三级 |
|---|---|---|---|
| 框架结构 | 0.65 | 0.75 | 0.85 |
| 框架-剪力墙、板柱-剪力墙、框架-核心筒、筒中筒 | 0.75 | 0.85 | 0.90 |
| 部分框支剪力墙 | 0.60 | 0.70 | — |

各注修正：

- **注 4**：剪跨比不大于 2 的柱（短柱）→ 限值 **−0.05**
- **注 5**：沿柱全高采用井字复合箍/复合螺旋箍等加密措施 → **+0.10**；
  加芯柱（芯柱截面面积不小于柱截面面积的 25%）→ **+0.05**
- **注 6**：限值**不应低于 0.65**

> 注 5 原文为"采用下列措施**之一**"，严格说各项不宜叠加。`codes.uc_limit_rc` 按可叠加处理
> 并以 1.00 封顶，是否叠加请以项目抗震审查意见为准。

设计式：`A ≥ Nu / (uc_lim · fc)`，`b = ceil(sqrt(A) / 50) × 50`。

## 3 型钢混凝土柱（十字型钢）

**JGJ3-2010 表 11.4.4 轴压比限值**

| 抗震等级 | 一级 | 二级 | 三级 |
|---|---|---|---|
| 限值 | 0.70 | 0.80 | 0.90 |

- 11.4.4 注：剪跨比≤2 时 −0.05；采用加密措施可 +0.10
- **11.4.5-6**：型钢含钢率 `ρa = Aa/A` **不宜小于 4%**
- **11.4.5-3**：型钢表面至柱面保护层 **≥150mm**

十字型钢截面积：`Aa = 4·f·t + 2·d·t − t²`
（`f` 翼缘宽、`t` 板厚、`d` 腹板高；4 片翼缘 + 2 片正交腹板，重叠处 t² 扣除）

设计式（取 `Aa = ρ·A`，`Ac = A − Aa`）：

    A ≥ Nu / ( uc_lim · ( fc·(1−ρ) + fa·ρ ) )

工具流程：按上式定初始 b，再从候选型钢族里挑满足 `保护层≥150`、`ρa∈[4%,5%]`
且 `Uc≤限值` 的规格；挑不到就加大 b。
未指定型钢族时按经验比例自动生成：`f ≈ 0.25b`、`d ≈ 0.65b`，板厚取标准档。
**经验比例仅供参考，正式项目请用设计确认的型钢规格（用 `src.steel` 或 `src.family` 传入）。**

## 4 钢管混凝土叠合柱

依据 **CECS188-2019《钢管混凝土叠合柱结构技术规程》**，口径已用 YJK 重算数据反标定：

| 项 | 表达式 | 限值 | 出处 |
|---|---|---|---|
| 管外轴压比 | `Uc = Nu / (fc外·A + fa·Aa)` | ≤ 0.85 | 4.2.14 |
| 含管率 | `Roa = Aa / A` | ≥ 3% | 4.2.13-4 |
| 套箍指标 | `θ = fa·Aa / (fc内·Ac内)` | ≤ 3.0（工程按 2.0 控） | — |
| 径厚比 | `D/t` | ≤ 89.37（Q355） | — |

几何约定：`b` 柱截面边长、`D` 内管外径、`t` 内管壁厚，
`Aa = π/4·(D² − (D−2t)²)`，`Ac内 = π/4·(D−2t)²`。

附加构造要求（工程约定，非规范强制）：

- **内管外径比柱截面小 650mm**（便于梁纵筋绕过），最少不小于 **600mm**
  （即管外到柱边 ≥300mm）。工具优先取 650，取不到时逐级放宽到 600。
- 标准层 5 的柱截面不应小于标准层 6 对应混凝土柱。

工具搜索顺序：柱截面 b 从小到大 → 净距从大到小 → 壁厚从小到大，返回第一个可行组合，
即"最小柱截面 + 尽可能大的净距"。

## 5 圆钢管混凝土柱

承载力（YJK 验算口径，已用 132 条真实结果反标定，RMS 偏差 0.004）：

    R_F1 = ( |N| + M_res/(0.25·D) ) / ( λ · N0 )      目标 0.80~0.88
    N0   = Ac·fc·(1 + α·θ)                              [kN]
    θ    = As·fa / (Ac·fc)
    Ac   = π/4·(D−2t)²     As = π/4·(D² − (D−2t)²)
    α    = 1.8（C55~C80）/ 2.0（≤C50）
    λ    = 0.904（C60/Q355）、0.907（C55/Q355）、0.909（C30/Q235）

> λ 不是规范系数，是把 YJK 内部验算结果反标定出来的**计算长度折减**。
> **换 YJK 版本或规范版本后必须重新标定**，否则 R_F1 不可信。

约束：`θ ∈ [0.5, 2.5]`、`D/t ≤ 89.37`。

选型准则：在允许的直径候选集内枚举 (D, t)，取**钢材用量最省**者（同用钢量取薄壁），
即优先"大直径薄壁"。若该组轴力偏小、θ 已到下限仍达不到 0.80，工具会返回最接近的组合
并标注"偏低"——这是正常结果，说明该组柱不是控制组。

## 复核输出字段

`check` / `design` 会回报：`Uc`（轴压比）、`Roa`（含管率）、`rhoa`（含钢率）、`theta`（套箍指标）、
`Dt`（径厚比）、`R_F1`（承载力利用率）、`净距mm`、`cover`（型钢保护层）。
把这些连同限值一起写进报告，便于审查。
