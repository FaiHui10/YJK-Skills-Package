# 柱截面形式经济比选（含 Excel 报告）

同一套内力、同一工程量口径下，比较**钢筋混凝土柱（RC）**与**钢管混凝土柱（CFST）**（矩形 / 圆形）的造价，给出截面选型与敏感性分析。

与 `column-section-opt` 的分工：它只做「矩形混凝土柱的截面 + 混凝土等级优选」，**不做柱型比选**；本技能专做柱型比选，内力输入通常取自它已实算复核的模型。

## 全流程（四条命令）

```
0) 前提：手上有一个 YJK 工程目录，内含 设计结果\wpj*.out（实算结果）
        以及对应的模型库 <模型>.ydb（用于读楼层信息）

1) col_data.py       ─► 柱设计数据.json      # 逐柱段内力 + 层高 + 现状工程量
2) cfst_design.py    ─► (被 3 调用)          # GB 50936-2014 承载力库，可单独自检
3) cost_model.py     ─► 造价对比.json        # 选型 + 计价 + 敏感性
4) report_xlsx.py    ─► <项目>_柱形式比选经济对比报告.xlsx
```

`col_data.py` 用 `--res <设计结果目录> --ydb <模型.ydb>` 指定本工程的数据源（也可用环境变量 `YJK_COL_RES` / `YJK_COL_YDB`）；分组按柱**平面坐标**现算，不依赖任何写死的柱号表。`report_xlsx.py` 可用 `--project <工程名> --out <xlsx>` 定制标题与文件名。其余脚本全部从 `柱设计数据.json` / `造价对比.json` 读入，无需改。

**缺数据不算成功**（`col_data.py` 的失败语义）：

- 关键字段缺失（Nu/Uc/Rs/Rsv、Ast/弯矩、层高、计算长度）、某个自然层没有 `wpj<自然层>.out`、或整层解析不出任何柱段时 → 打印缺项明细（点名自然层与缺失字段）并**非零退出**，**不写出 `柱设计数据.json`**（兜底成 0 会让下游算出更便宜、更细的方案；半成品 JSON 又会被下游按"文件存在"取用）。
- 柱位分组映射缺失（柱号在模型库 `tblColSeg` 里找不到对应柱段，组记为 `?`）不是致命项：醒目提示并记入 `meta.分组缺失段数` / `meta.分组缺失自然层`（受影响的行另有 `"分组缺失": true`）；要求这一项也判失败时加 `--strict`。
- 自动化调用方必须检查退出码：只有 rc=0 才说明 `柱设计数据.json` 完整可用。

```powershell
# 解释器不要写死：优先用 yjk-auto-drive 探测/记录的那个（也可先跑 setup_env.py）
$py = Get-Content "$HOME\.yjk-auto\python.txt" -ErrorAction SilentlyContinue
if (-not $py) { $py = "python" }
& $py -X utf8 -B scripts\col_data.py --res <设计结果目录> --ydb <模型.ydb>
& $py -X utf8 -B scripts\cost_model.py
& $py -X utf8 -B scripts\report_xlsx.py --project "<工程名>" --system "框筒" --seismic "二级"
```

本技能**不调用驱动**（纯解析 + GB 50936 计算），无 `find_driver()` 依赖；改完脚本仍建议跑可移植性自检：`python <yjk-auto-drive>\scripts\portability_check.py`（退出码 0 = 通过）。

## 第一步：内力与几何口径

**唯一的数据源是 `设计结果\wpj<自然层>.out`（GBK 编码）+ 模型库 `tblFloor`。**

### 层高必须用 `tblFloor.Height`，不能用 `tblStdFlr.Height`

`tblStdFlr.Height` 只是标准层的**代表值**，与其中各自然层的实际层高可以不同，用错会显著高估工程量。`tblFloor.Height`（mm）与 `wmass.out`「各层构件数量、构件材料和层高」表**逐层一致**，用它核对总高。

### `wpj*.out` 的几何行语义

```
Cover= 20(mm) Cx=1.00 Cy=1.00 Lcx=6.00(m) Lcy=6.00(m)
```
- **`Cx`/`Cy` = X/Y 向「计算长度系数」**（不是长度！）
- **`Lcx`/`Lcy` = X/Y 向「柱段设计长度」(m)**
- 正确关系：**`L0x = Cx × Lcx`，`L0y = Cy × Lcy`**
- **跃层柱**的 `Lcx`/`Lcy` 等于所跨多个自然层层高之和（例如跨 6.0m + 5.0m 两层时 `Lcx=6.00, Lcy=11.00`）。**两个方向必须各取各的，绝不能两向都用 `Lcx`。**

判定跃层：`max(Lcx, Lcy) > 层高 × 1.05`。

### 弯矩必须取包络，不能只留最后一次

`RE_AS` 形式的行在同一组合下**出现 4 次**（Asxt / Asyt / Asxb / Asyb），分别对应**柱的上端与下端**，例如：

```
(  1)N=  -15580.7 Mx=     750.5 My=    -192.4 Asxt=      1744
(  1)N=  -15580.7 Mx=     750.5 My=    -192.4 Asyt=      2330
(  1)N=  -15580.7 Mx=    -329.9 My=      93.2 Asxb=      1744
(  1)N=  -15580.7 Mx=    -329.9 My=      93.2 Asyb=      2330
```

字典按组合号覆盖写入后**只剩最后一条的弯矩**（上例 329.9 而非 750.5），低估 2 倍以上，必须逐条累计：

- `M_comp_absmax` = max over 所有行 of max(|Mx|, |My|)   —— 分向包络
- `M_res_absmax` = max over 所有行 of hypot(Mx, My)      —— 合弯矩包络（**设计取值**）
- 四边配筋之和 − 4×角筋 = 纵筋总面积（角筋在相邻两边各计 1 次）

### 轴力取 `RE_CTRL` 的 `Nu`

( 29)Nu=  -16283.9  Uc= 0.72  Rs= 0.75(%)  Rsv= 1.30(%)  Asc= 490

取 |Uc| 最大（即该 SLC）的那条。它可能**大于**设计组合行里的 max|N|，因为 wpj 只列出控制配筋的部分组合。

## 第二步：GB 50936-2014 承载力（`cfst_design.py`）

公式已逐条比对规范原文，见 `references/gb50936.md`。要点：

```
N0  = Asc·fsc                                          (5.1.2-1)
fsc = (1.212 + B·θ + C·θ²)·fc , θ = αsc·fy/fc , αsc = As/Asc   (5.1.2-2~4)
Nu  = φ·N0                                             (5.1.10-1)
λ̄sc = 0.01·λsc·(0.001fy + 0.781) , λsc = l0/i          (5.1.10-3)
Mu  = γm·Wsc·fsc , Wsc = πr0³/4 , r0 = √(Asc/π)        (5.1.6-1~2)
γm  = 1.2（圆形）；= −0.483θ + 1.926√θ（其他截面）       (5.1.6-3)
U ≥ 0.255: N/Nu + βm·M/[1.5Mu(1−0.4N/N'E)] ≤ 1         (5.3.1-4)
U < 0.255: −N/(2.17Nu) + βm·M/[Mu(1−0.4N/N'E)] ≤ 1     (5.3.1-5)
```

**易错点**

- 表 5.1.2 形状系数：B 只与 fy 有关、C 只与 fc 有关。矩形需换算成**等效正方形** `be = √(b·h)`。
- 回转半径：**圆管 `i = D/4`**（用 √(I/A) 也能得到同样结果，但用 D/4 最稳）；矩形 `i = √(I/Asc)`，两方向分别算再取 λ 大者。
- `N'E` 用 **11.6·kE·fsc·Asc/λsc²**（式 5.3.1-3），不是 π²EscAsc/λ²。
- 目标利用率建议同时施加于 **U_ax = N/Nu** 与 **U_NM（压弯综合）**：只控 U_ax 会出现 U_NM ≈ 0.99 的隐性超限。本技能默认两者都按 target 控。

**构造约束**（`check()` 全部强制）

| 约束 | 限值 | 条文 |
|---|---|---|
| 套箍系数 θ | **宜 0.5~2.0** | 4.3.2 |
| 壁厚 | ≥ 3mm（本技能取 ≥6mm 常用值） | 4.3.1 |
| 圆管外径/矩形边长 | ≥ 168mm | 4.3.1 |
| 圆管 D/t | ≤ 100 | 常用构造 |
| 方/矩形 b/t | ≤ 60 | 常用构造 |
| 矩形柱轴压比 μN | ≤ 0.80（二级框筒） | 表 4.3.10 |
| 框架柱长细比 [λ] | ≤ 80 | 4.1.7 |

## 第三步：广州地区计价（`gz_quota.py`）

依据：**《广东省房屋建筑与装饰工程综合定额（2018）》** + **广州市信息价**。全部定额子目、基价、人工/材料/机具/管理费与信息价都硬编码在 `gz_quota.py` 里并注明来源，见 `references/quota-guangzhou.md`（含**如何核对/更新子目**）。

**取费规则（必须照此，不要自己编）**
```
综合单价(除税) = 定额人工×指数 + 定额材料 + 定额机具×指数 + 管理费×指数
                 + (定额人工 + 定额机具) × 20%   ← 利润
管理费率（已含在定额基价里）：混凝土及钢筋混凝土 28.75% / 模板 26.35%
                              / 金属结构 28.94% / 油漆涂料 15.07%
增值税 = 综合单价 × 9%
```
- **现浇柱定额基价不含混凝土材料**，混凝土按信息价 ×(1+1.0% 损耗) 另加。
- 钢筋子目要**先扣掉定额内含钢筋价再换入信息价**（`REBAR_DOSE` / `REBAR_QUOTA_PRICE`）。
- 柱模板按**周长**选子目（1.2m 内 / 1.8m 内 / 1.8m 外），支模高度 >3.6m 者**每增 1m 叠加 A1-20-19**（不足 1m 按 1m 计）。
- 钢柱安装定额里**钢柱是「未计价主材」**，须另计 `钢板信息价×(1+下料损耗) + 制作加工费`。
- 钢管混凝土按 GB 50936 工程量规则：节点板/加强环/内衬管/牛腿**并入钢管柱质量**；管内混凝土按**钢管内径**算体积。

**必须做成敏感性分析的非定额项**（市场估值）
| 项 | 基准 | 敏感范围 |
|---|---|---|
| 钢管柱制作加工费 | 1300 元/t | 1100~1600 |
| 钢板下料损耗 | 5% | — |
| 节点附件系数 | 1.08 | 1.00~1.15 |
| 防火涂料子目 | 厚型H 3.0h(30mm) A1-15-135 | CB/B/H 各档、以及"不计" |
| 套箍系数下限 θ | 0.50（规范推荐） | 0 与 0.70 |
| 目标利用率 | 用户指定（默认 0.90） | 0.80 / 0.85 / 1.00 |
| 人工费价格指数 | 1.000（不调） | 1.0913（广州现行指数） |

## 第四步：方案设计

比选必须有**可比锚点**，建议至少给这几种：

| 方案 | 外轮廓 | 能回答什么问题 |
|---|---|---|
| S1 RC | 原柱 | 基准 |
| S2 矩形 CFST | **= 原柱 b×h** | 柱宽/柱位不变时贵多少（可与 S1 直接比） |
| S3 圆形 CFST | D = √(4bh/π)（等面积） | 占用面积不变时贵多少 |
| S4 圆形 CFST | 扫 D 取造价最低 | 允许缩小柱截面时的最优 |
| S5 圆形 CFST | 同 S4 但不限 θ | 规范推荐值的代价 |
| S6 矩形 CFST | 保长宽比扫短边取造价最低 | 矩形的最优 |

**S2/S3 才是「同等外轮廓」的公平对比**；S4/S6 缩小了柱截面，必须同时给出**柱平面占用面积的变化**（典型可减少 30%~40%），否则会低估其价值。

## 交付物：Excel 报告（`report_xlsx.py`）

页签结构（9 页，可直接照用）：

1. `1-说明` —— 工程概况、**比选范围**、内力输入口径、承载力控制、计价依据、**造价构成要点**、主要结论、限制与风险、结论建议
2. `2-造价汇总对比` —— 分项 + 除税 + 含税 + 相对 S1 + **元/kN** + 元/延米柱（+柱状图）
3. `3-工程量对比` —— 实物量 + 分项造价 + **单位造价(元/单位)** + 分项占比
4. `4-钢管混凝土截面选型` —— 各设计点 × 各方案的外轮廓/t/θ/U_ax/U_NM/造价
5. `5-现状钢筋混凝土柱(基准)` —— 逐设计点工程量与造价（含 Rs/Rsv/短柱数）
6. `6-敏感性分析` —— 各种假设下的总造价与比值
7. `7-定额与价格依据` —— 定额子目全表 + 取费规则 + 信息价全表 + 非定额项
8. `8-逐柱明细` —— 内力输入 + 各方案逐柱段造价（可与汇总对账）
9. `9-复核与决策清单` —— 必须实算复核的项 + 决策要点

**硬要求**
- **必须写"范围/口径声明"**：哪些是实算、哪些是估算、哪些费用未计入。
- **必须给敏感性分析**，且**每个情形都重新执行截面选型**（不是系数折算）。
- **必须与汇总对账**：`8-逐柱明细` 的分项合计要等于 `2-造价汇总对比` 的合计。
- 单向结论要留反向证据：把"钢管混凝土更贵"的同时，也列出它的有利之处（无箍筋、自重小、柱截面可缩小 → 使用面积）与未计入项（基础、工期）。

报告里凡「实测／现算」的结论都带无数据分支：截面表为空或缺项、「敏感性」为空或缺失、柱位分组未归组、某个方案没有外轮廓时，一律写「无数据／该项未校验（不得当满足用）」，不兜底成 0，也不写成「满足」「减少 100%」。看到「无数据」说明上游某一环缺数据，应先去补齐，不要把该报告当作通过；承载力利用率栏若写「数据不完整（N 个「方案 × 设计点」缺 U 值）」，表示覆盖率不足，同样不得当满足用。

## 量级参照

以框筒结构、高度约 130m、数百个柱段、混凝土 C40~C60 的工程为参照：

| 方案 | 除税造价 | 相对 S1 |
|---|---|---|
| S1 钢筋混凝土 | 100% | 基准 |
| S2 矩形 CFST（等外轮廓） | 约 300% | 最贵 |
| S6 矩形 CFST（造价最优） | 约 260% | |
| S3 圆形 CFST（等外轮廓） | 约 240% | |
| S4 圆形 CFST（造价最优） | 约 150% | |
| S5 圆形 CFST（不限 θ） | 约 150% | |

**原因**：钢管综合单价（钢板信息价×(1+下料损耗) + 加工费 + 安装）约 **6 400~6 500 元/t**，而钢筋综合单价仅 **约 4 000 元/t（纵筋）/ 4 300 元/t（箍筋）**；钢管混凝土方案的「钢管材料+安装」占其造价 **2/3 以上**，另加防火涂料 10% 以上。**单位质量钢材做钢管比做钢筋贵 50%~60%，且用钢量并未减少。**

现行广州价格下，各种假设组合中钢管混凝土**始终更贵**（最乐观情形 ——「假设防火涂料由建筑包覆解决、不计入造价」—— 仍贵约 27%）。

## 已知边界

- 用**原 RC 模型的柱内力**做输入。柱形式改变会影响抗弯刚度 → 内力重分布、层间位移角、层刚度比，**必须重算验证**，本技能不做整体实算。
- 同组多柱段按 **ΣN、max M、max L0 取包络**设计，偏安全，但不是精确的逐柱设计。
- **不含**基础/桩基、除锈油漆、焊缝探伤、大型吊装机械、梁柱节点专项构造、管内混凝土特殊浇筑工艺、收缩徐变控制措施。这些**多数使钢管混凝土更贵**。
- **不含工期与施工难度差异**（钢管柱工厂化预制对超高层工期通常有利）。
- 矩形 CFST 用**等效正方形**换算 fsc，是个近似；精确值需查规范附录或做试验。
- 只比「柱」；梁、板、墙、基础、荷载一律不变。
- 「每层 N 根框架柱」按**逐自然层现算**给出（各层不等时写成区间「每层 a~b 根」）；报告不读 `wmass.out`，总高是否与 `wmass.out` 逐层一致属**人工核对项**（报告已如此标注）。
- 逐柱段的 `Nu` / 层高缺失时报告直接失败（不渲染成 0）：这两项是 5-现状RC 表与「元/kN、元/延米柱」等指标的主键/分母，缺了整表无意义；正常流程下 `col_data.py` 已保证 rc=0 时它们非空。

## 编码约定（生成代码与文件时必须遵守）

本包在简体中文 Windows 上运行，控制台与部分工具默认用 GBK。下面的约定是硬的：
这里出问题时**多数不报错**，只是静默给错结果，或把成功判成失败。

1. 源码与文本产物一律 **UTF-8、无 BOM**；`.py` 首行写 `# -*- coding: utf-8 -*-`。
2. 所有 `open()` 显式 `encoding=`：普通文本 `utf-8`；人可能用记事本改过的配置/标志文件用
   `utf-8-sig`（BOM 会被当成正文）。二进制模式除外。
3. 读 YJK 自己的输出（`*.out`、`设计结果\*.txt`、`中间数据\*`、`dsnctrl.ini`）用 **`gbk`**
   （`errors="replace"`）。用 UTF-8 读会乱码，而且通常不报错，只是解析出 0 条。
4. `print` 里含非 GBK 字符（`✅❌⚠²³−` 等）时，本文件必须调用 `_utf8_console()`，并且要在
   `main()` 里调用一次；只在 `if __name__ == "__main__"` 分支里调用时，被别的脚本 import
   当库用仍会在 GBK 控制台崩（退出码 1，明明成功却判成失败）。没有 `main()` 的库模块，
   放在对外入口函数里。新增输出优先用 ASCII 标记（`[OK]` / `!!`）。
5. 子进程抓文本：`text=True, encoding="utf-8", errors="replace"`；调用本包脚本加 `-X utf8`
   并传 `PYTHONIOENCODING=utf-8`。
6. 写 JSON 用 `ensure_ascii=False` + `encoding="utf-8"`，中文才可读。
7. 生成 `.bat` / `.ps1` 若含中文，先 `chcp 65001 >nul`，否则只用 ASCII。

静态检查：`python yjk-auto-drive\scripts\encoding_check.py`（0 = 合规）。
完整规则与"不遵守会怎样"的对照见 `AGENT-COMPAT.md` 的「编码约定」一节。
