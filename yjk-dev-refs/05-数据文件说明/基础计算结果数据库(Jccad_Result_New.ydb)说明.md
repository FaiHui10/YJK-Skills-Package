基础计算结果数据库(Jccad_Result_New.ydb)说明
概述
基础计算结果对应的数据库文件为Jccad_Result_New.ydb，存储位置在“工程路径\基础计算及结果输出\Jccad_Result_New.ydb”。目前主要用于将基础计算结果传递给第三方或二次开发，如GAMA。
生成该ydb方法：
[图]
勾选改选项后，进行基础计算，即可生成该ydb。
数据库版本号
数据库版本（ver）

| 字段名 | 字段类型 | 字段含义 |
|---|---|---|
| ID | 整型 | 编号 |
| version | 文本 | 最后一次使用的版本号 |
