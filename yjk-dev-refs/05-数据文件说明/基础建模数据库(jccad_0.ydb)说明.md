# 基础建模数据库(jccad_0.ydb)说明

## 1、概述

基础模型对应的数据库文件为jccad_0.ydb，存储位置在“工程路径\jccad_0.ydb”。

## 2、计算参数表

|    字段名     | 字段类型 | 允许为空 | 主键 |             字段含义              |

|    字段名     | 字段类型 | 允许为空 | 主键 |    字段含义    |
|:-------------:|:--------:|:--------:|:----:|:--------------:|

| **LoadIndex** |   整型   |    否    |  否  |   抗浮力类型   |
| **LoadCoef**  |  浮点型  |    否    |  否  | 抗浮力组合系数 |
| **LoadName**  |   文本   |    否    |  否  |   抗浮力名称   |
